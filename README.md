# Ishini Awanka Ranathunga — Personal Portfolio

A responsive black-and-pink portfolio made with HTML, CSS and vanilla JavaScript, featuring software engineering, QA and computer vision projects.

## Files

- `index.html` — GitHub Pages entry point
- `index.css` — styling and responsive layout
- `script.js` — mobile navigation and project filtering
- `profile.png` — portfolio photo
- `assets/cv/*.pdf` — public-facing SE and QA CVs for the two download buttons

The downloadable public CVs intentionally omit references' personal contact details. The original editable Word CVs have not been changed.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000/ and check both CV download buttons, project filters and mobile menu.

## Publish on GitHub Pages

1. In `Ishini01/ishini01.github.io`, upload all files **and the `assets/cv` directory**, preserving the paths.
2. The landing page must be named `index.html`.
3. Commit changes to the branch configured for Pages (normally `main`), or open a pull request and merge after review.
4. Confirm the site renders and both PDF downloads work.

GitHub profile: https://github.com/Ishini01

## Note about project links

Only public GitHub repositories are linked. GoalReflect and TodoMVC are displayed without fabricated public links.
